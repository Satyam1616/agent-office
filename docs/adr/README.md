# Architecture decision records

Short notes on decisions that shape the project, written so nobody has to re-derive the
reasoning later. One file per decision, numbered in the order they were taken.

A record is not edited once merged, apart from fixing mistakes. When a decision changes,
add a new record that supersedes the old one and say so in both, so the history of why
stays readable.

Each record says what the situation was, what was decided, what that makes easier and
harder, and — most usefully — what would have to become true for the decision to be worth
revisiting. That last part is what turns "maybe later" into a condition you can check.
