# Sounds

Looping machine sounds for the factory view. All are **CC0 1.0** (public domain) from
[Freesound](https://freesound.org), downloaded from the HQ previews, trimmed to their steady
section, made mono and loudness-normalized with ffmpeg.

| File          | Source                                                                                                   | Author             | Used for            |
| ------------- | -------------------------------------------------------------------------------------------------------- | ------------------ | ------------------- |
| `cnc.mp3`     | [Entire CNC process](https://freesound.org/people/soundsofscienceupf/sounds/460831/) (0:49–1:12)         | soundsofscienceupf | ⚙️ CNC Mill         |
| `laser.mp3`   | [Robotic Laser Cutter with Loud Ventilator Fan](https://freesound.org/people/SoundsofTheMachine/sounds/770385/) (0:08–0:53) | SoundsofTheMachine | ⚡ Laser Cutter     |
| `stepper.mp3` | [CNC Stepper Motors](https://freesound.org/people/squashy555/sounds/614362/) (0:05–0:57)                  | squashy555         | 🖨️ 3D Printer       |
